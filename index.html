Ο ίδιος κύκλος σε κάθε project, είτε είναι μία σελίδα είτε ολόκληρο brand. Ξέρεις πάντα σε ποιο σημείο του βρίσκεται η δουλειά σου.

Μπαίνουμε σε ένα project σαν προέκταση της ομάδας σου. Ο πελάτης παραμένει δικός σου. Η επικοινωνία και η παρουσίαση περνάνε πάντα από εσένα. Ό,τι μοιράζεσαι μένει εμπιστευτικό και τίποτα δεν δημοσιεύεται χωρίς την έγκρισή σου. Εσύ κρατάς το τιμόνι. Δίνεις το brief, κάνεις το review, αποφασίζεις τι φτάνει στον πελάτη. Και όταν πιέζει, μπαίνουμε για ένα project ή για μια ολόκληρη περίοδο.

Έχεις project με διαφορετικό scope;

Για οποιοδήποτε project μπορούμε να συζητήσουμε ξεχωριστά τις ανάγκες, τις απαιτήσεις και τα παραδοτέα, ώστε να διαμορφωθεί η τελική προσφορά με βάση το πραγματικό εύρος εργασίας.
